# Medialog Sign: модуль интеграции с КриптоПро

Исходный каркас интеграции КриптоПро CSP/CAdES для Windows Desktop. В комплекте:

- `windows_bridge/` — Windows x64 helper на C#/.NET Framework 4.8, работающий через зарегистрированные COM-объекты CAdESCOM;
- `flutter/lib/integrations/cryptopro/cryptopro_bridge_client.dart` — Dart-клиент для вызова helper из Flutter;
- `docs/` — архитектура, требования к среде и тестовый план.

## Реализованные команды

- `status` — проверка регистрации COM-компонентов CAdESCOM;
- `list-certificates` — чтение сертификатов из хранилища `CurrentUser/My`;
- `sign-detached` — создание отсоединённой CAdES-BES подписи;
- `sign-attached` — создание присоединённой CAdES-BES подписи;
- `verify-detached` — криптографическая проверка отсоединённой подписи.

## Важно

Это исходный интеграционный модуль, а не подтверждённая производственная сборка. Среда выполнения здесь не Windows, поэтому COM-интеграция и криптографические операции не могли быть исполнены в текущем окружении. Перед использованием нужно собрать helper и проверить его на целевой Windows-машине с установленными и лицензированными компонентами КриптоПро.

Модуль не экспортирует закрытые ключи, не запрашивает и не сохраняет PIN-коды. Доступ к ключу и возможный PIN-диалог обрабатываются установленным криптопровайдером. Криптографическая проверка подписи сама по себе не подтверждает доверие к цепочке сертификата или отсутствие отзыва: это отдельные проверки.

Не используйте в продуктивной среде тестовые сертификаты, демо-токены или секреты из конфигураций примеров. Не включайте в журнал PIN-коды, содержимое закрытых ключей или полные персональные данные.
