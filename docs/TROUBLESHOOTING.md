# Диагностика

## CMake: `cades.h not found`

Проверьте:

```powershell
Test-Path 'C:\Program Files (x86)\Crypto Pro\SDK\include\cades.h'
```

Если SDK установлен в другом месте, передайте корректный `CRYPTOPRO_SDK_ROOT`.

## Linker: `cannot open cades.lib`

Для x64 нужна именно:

```text
SDK\lib\amd64\cades.lib
```

Не использовать Win32 `SDK\lib\cades.lib`.

## Bridge не запускается: missing `cades.dll`

`cades.lib` является import library. Во время запуска Windows загружает `cades.dll`. Установите соответствующий CAdES x64 runtime штатным MSI. Не скачивайте отдельную DLL с неизвестных сайтов.

## `cadesDllLoaded=false`

Если exe всё же запустился, проверьте runtime path, разрядность и фактическое имя DLL. При обычной import dependency отсутствие DLL может привести к ошибке загрузчика до вызова `status`.

## Список сертификатов пуст

Проверьте в `certmgr.msc` хранилище текущего пользователя:

`Личное → Сертификаты` (`CurrentUser\\MY`).

Если сертификат установлен в LocalMachine, текущая версия его не перечисляет. Проверьте, что приложение запущено под ожидаемой учётной записью.

## `CERTIFICATE_NOT_FOUND`

Thumbprint должен быть SHA-1 отпечатком именно сертификата в CurrentUser\\MY. Пробелы и двоеточия нормализуются, но другие символы удаляются только при нормализации hex.

## `PRIVATE_KEY_NOT_LINKED`

У сертификата не найдено свойство связи с private key. Проверьте импорт PFX с ключом, привязку к CSP контейнеру, токен и пользователя. Сам факт наличия публичного сертификата не означает, что закрытый ключ доступен.

## `UNSUPPORTED_KEY_ALGORITHM`

Текущий mapping содержит три OID ГОСТ. Для иного OID нужно добавить поддержку после проверки по документации и требованиям принимающей системы, а не подставлять случайный хеш.

## `CADES_SIGN_FAILED`

Проверьте код Win32 error в сообщении, CSP installation/license, права доступа к контейнеру, PIN/token state, сертификат и совместимость runtime/SDK. Если PIN UI требуется, запускайте интерактивно в пользовательской сессии.

## Файл не создаётся

Проверьте права на каталог, блокировку файла другим процессом, наличие свободного места и допустимость перезаписи. Выходной путь должен быть доступен Windows account процесса.

## `INVALID_BRIDGE_RESPONSE` в Flutter

Проверьте, что запускается правильный exe, `stdout` содержит только JSON и версии Dart-протокола/Bridge согласованы. Технические сообщения нельзя печатать в stdout.
