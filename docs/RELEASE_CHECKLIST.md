# Release checklist

## Build

- [ ] Windows x64 build проходит в Release.
- [ ] Нет смешения x86/x64 headers, libs и runtime.
- [ ] Версия toolchain и SDK зафиксирована.
- [ ] Bridge запускается на чистой целевой ОС после штатной установки зависимостей.
- [ ] `status` и `list-certificates` возвращают валидный JSON.
- [ ] stdout не содержит лишних сообщений.

## Crypto

- [ ] Тестовый сертификат с доступным private key виден.
- [ ] Detached CAdES-BES формируется.
- [ ] Attached CAdES-BES формируется.
- [ ] Оба результата проходят независимую проверку.
- [ ] Изменённый документ не проходит verify.
- [ ] Ошибки PIN/token/provider обрабатываются предсказуемо.
- [ ] Профиль/формат принят принимающей системой.
- [ ] Trust, revocation и timestamp policy проверены отдельно.

## Security / operations

- [ ] Нет PIN/паролей в конфигурации, аргументах, логах.
- [ ] Закрытый ключ не экспортируется.
- [ ] Доступ к входным/выходным каталогам ограничен.
- [ ] Аудит и политика хранения определены.
- [ ] Указан владелец сертификата/ключа и процедура отзыва.
- [ ] RDP / Server session model испытана.
- [ ] Для background signing разработан отдельный worker, если он требуется.

## Documentation

- [ ] README и все docs соответствуют версии кода.
- [ ] Известные ограничения и unsupported алгоритмы указаны.
- [ ] Compatibility matrix заполнена конкретными версиями.
- [ ] Тестовый отчёт и release manifest приложены.
