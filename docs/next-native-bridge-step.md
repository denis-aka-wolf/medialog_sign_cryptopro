# Следующий шаг реализации

Нативный C++ Bridge добавлен в `native/`. Следующий обязательный шаг выполняется на Windows x64 с установленным CryptoPro CSP/CAdES runtime и Visual Studio 2022:

1. Выполнить `scripts/build-bridge.ps1`.
2. Исправить возможные отличия toolchain/SDK после фактической компиляции.
3. Выполнить `scripts/test-bridge.ps1`.
4. Провести тесты подписания и проверки по `TESTING.md` на тестовом сертификате.

До успешного выполнения этих шагов Bridge считается исходным прототипом, а не проверенной бинарной поставкой.
